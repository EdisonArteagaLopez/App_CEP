# App CEP

Android application for Complex Event Processing (CEP) — detects patterns from streams of sensor or IoT events.

## Features
- Event stream processing
- Pattern detection and alerting
- IoT device integration

## Requirements
- Android Studio
- Android SDK 21+

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/App_CEP.git
```
Open in Android Studio → Build → Run
